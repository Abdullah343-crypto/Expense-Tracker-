# Style Guide — Expense Tracker

- Visual direction: calm, clear finance utility with minimal layout and readable amounts.
- Primary: Forest green — #256D5A
- Secondary: Soft mint — #DCEFE8
- Background: Off-white — #F7F9F8
- Main text: Charcoal — #202824
- Supporting text: Grey — #68736E
- Error: Dark red — #B3261E
- Typography: Roboto (Android default); screen title 24 sp bold, section heading 18 sp semibold, body 14–16 sp, amounts 20–24 sp bold.
- Components: rounded cards (12–16 dp), filled primary buttons, outlined inputs, category chips, 16 dp screen padding and 48 dp minimum touch targets.
- Accessibility: high contrast, labels for icons, don't communicate categories by colour alone, support system text scaling.
