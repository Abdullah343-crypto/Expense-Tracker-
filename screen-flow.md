# Screen Flow and Wireframe Notes

## Screen flow
Welcome → Dashboard → Expense List → Expense Details → Edit Expense
Dashboard → Add Expense
Dashboard → Reports
Dashboard → Settings

## Planned wireframes
1. Welcome: app icon, name, short description and Get Started button.
2. Dashboard: selected month, total spending card, category summary, recent expenses and Add button.
3. Expense List: search field, category filter chips, sort control and expense rows.
4. Add Expense: title, amount, date, category, camera receipt button and Save button.
5. Expense Details: title, amount, date, category, receipt preview, Edit and Delete actions.
6. Edit Expense: pre-filled expense form and Save Changes button.
7. Reports: monthly total and category-wise chart.
8. Settings: currency preference, data/privacy information and About.

These are low-fidelity wireframe descriptions. Export actual Figma frames and include them in the final report if your instructor requires visual wireframe files.
