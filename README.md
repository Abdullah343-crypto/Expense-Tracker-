## Project description
Expense Tracker is a simple mobile application that helps students and young adults record, organize and review daily spending. Users can add, view, edit and delete expense records, assign categories, and search or filter transactions. A dashboard shows total spending and a category-wise overview. Data is planned to be stored locally so the app can work offline.

## Target users and value
Students and young adults who want a quick way to track everyday expenses. The app aims to provide a lightweight and easy-to-use alternative to complex finance apps.

## Feature scope
### Must
- Add, view, update and delete an expense.
- Save expenses locally on the device.
- Show an expense list and total spending.
- Search by title and filter by category.
- Attach a receipt photo using the camera.
### Should
- Sort by date or amount.
- Show a monthly spending summary.
- Validate required fields and amounts.
### Could
- Export records to CSV.
- Optional cloud backup in a later version.

## Planned screens
Welcome, Dashboard, Expense List, Add Expense, Expense Details, Edit Expense, Reports, Settings.

## Tech stack

## Setup
1. Install Flutter SDK and Android Studio.
2. Configure an Android emulator or connect an Android phone with USB debugging.
3. Run `flutter doctor` and resolve Android toolchain issues.
4. Open this project folder in VS Code or Android Studio.
5. Run `flutter pub get`.
6. Run `flutter run` on the selected Android device.
